# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues, discussions, pull requests, or commit messages.

Use the repository's private vulnerability reporting flow when it is available. If private vulnerability reporting is not available for the affected repository, contact @wcypierre through GitHub before sharing exploit details publicly.

Include as much non-sensitive context as possible:

- Affected repository and component
- Impact and severity
- Steps to reproduce, proof of concept, or affected configuration
- Suggested mitigation, if known

## Response Expectations

Reports are handled on a best-effort basis. There is no guaranteed response time or disclosure schedule unless a repository documents a stricter policy.

## Scope

This default policy applies only when a repository in this organization does not provide its own `SECURITY.md`.
