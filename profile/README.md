# wcypierre-org

This organization hosts small tools, automation projects, integrations, and experiments maintained by @wcypierre.

Most repositories are built for practical use first: clear setup, repeatable verification, conservative automation, and small focused changes.

## Find a Project by Task

| Task | Projects |
| --- | --- |
| Jira reading, tracking, dashboards, and automation | `jira-tracker`, `jira-reader`, `jira-ui`, `jira-server-api`, `jira-assistant-api`, and the focused Jira integrations |
| Media discovery, playback, and organization | `anime-download`, `anime-listing`, `immich-album-swipe`, `carousel-extractor` |
| Personal reminders, diaries, and monitoring | `timeline-diary`, `publicholiday-tracker`, `SimMonitor`, `sim-monitor-expiry-update`, `omada-at-home-monitor` |
| Browser and device automation | `tab-snooze`, `tiktok-auto` |
| Calls, feeds, and external integrations | `freepbx-call-api`, `ttrss-to-jira`, `youtube-to-jira`, `deluge-to-jira` |
| CI, security, governance, and runners | `application-workflows`, `security-workflows`, `governance-workflows`, `fleet-catalog`, `github-monitor`, `github-runner-setup`, `runner-control-plane` |

See the complete [repository and maintenance directory](../REPOSITORIES.md) for every active project, its purpose, lifecycle, and support route.

## Working With These Repositories

- Open a bug report when something does not work as documented.
- Open a feature request when you have a concrete use case.
- Read the repository README and any local `AGENTS.md` before proposing changes.
- Keep pull requests focused and include the commands or checks you ran.
- First-time contributors can use the [contributor onboarding checklist](../CONTRIBUTOR_ONBOARDING.md).

## Security

Please do not report security vulnerabilities in public issues. See the organization security policy in `SECURITY.md` for the preferred reporting flow.
